Overview

Marco del proyecto

VitaPlus Colombia simula un negocio retail de salud en Colombia con clientes, productos, ventas y calendario. El objetivo fue practicar el flujo completo desde archivos CSV/TXT hasta análisis en Fabric y Power BI.

Contexto

El proyecto usa una empresa ficticia y datos completamente sintéticos para evitar información personal, pacientes reales o reclamaciones médicas reales.

Objetivos técnicos

  • Creación de tablas SQL
  • Carga de archivos CSV/TXT
  • Ingesta en Lakehouse y Warehouse
  • Modelado de hechos y dimensiones

Flujo analítico

El caso conecta datos sintéticos con Delta tables, SQL Analytics Endpoint, Semantic Model y un reporte Power BI usando una lógica estilo DirectLake cuando es posible.

Workflow

Proceso de construcción

El flujo combina diseño del dataset, generación de archivos, carga en Fabric, modelado semántico y exploración visual en Power BI.

  1. Diseño prompt-driven del dataset sintético.
  2. Generación de archivos CSV/TXT.
  3. Upload al Fabric Lakehouse.
  4. Load to Tables para crear Delta tables.
  5. Consulta mediante SQL Analytics Endpoint.
  6. Ingesta opcional al Warehouse.
  7. Creación del modelo semántico.
  8. Construcción del reporte Power BI.
  9. Exploración de insights de negocio.

Carga en Lakehouse

  • Abrir el panel del Lakehouse.
  • Subir CSVs en Files/vitaplus/.
  • Seleccionar cada archivo.
  • Usar Load to Tables.
  • Fabric crea tablas Delta automáticamente.
  • Acceder por SQL Analytics Endpoint o notebooks PySpark.

Carga en Warehouse

El Warehouse puede alimentarse con COPY INTO o con el wizard de ingesta de Fabric.

COPY INTO dbo.clientes
FROM 'https://tu_storage.dfs.core.windows.net/vitaplus/clientes.csv'
WITH (FILE_TYPE='CSV', FIRSTROW=2);

Modelo estrella en Power BI

  • Conectar al SQL Endpoint.
  • Marcar ventas como tabla de hechos.
  • Usar clientes, productos, calendario y sedes como dimensiones.
  • Configurar relaciones.
  • Usar modo DirectLake cuando sea posible.
