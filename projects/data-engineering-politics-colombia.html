Overview

Marco del proyecto

Este proyecto implementa una arquitectura moderna de datos (Medallion) para transformar registros políticos crudos en insights accionables, permitiendo el análisis de resultados electorales y comportamiento legislativo.

Objetivo

Crear una plataforma de datos escalable que centralice la información política dispersa y automatice su procesamiento.

Flujo de trabajo

  • Ingestión de datos a Fabric Lakehouse
  • Limpieza y transformación con PySpark
  • Modelado dimensional (Estrella) en SQL
  • Visualización analítica en Power BI

Qué muestra esta página

La arquitectura del sistema, el flujo de datos y los resultados visuales del dashboard de análisis político.

Análisis Visual

Arquitectura y Visualizaciones

El proyecto se estructura en tres capas principales: infraestructura, flujo de procesamiento y entrega de valor visual.

1. Infraestructura y Diseño

Diseño de la arquitectura del sistema y el modelo de datos para garantizar escalabilidad y rendimiento.

Gráfico 01

Arquitectura del Sistema

Implementación en Microsoft Fabric utilizando Lakehouse para almacenamiento y notebooks de PySpark para la orquestación del procesamiento Medallion.

Esta arquitectura permite separar el cómputo del almacenamiento, facilitando el escalado independiente y el uso de múltiples lenguajes (Python, SQL) sobre los mismos datos.

Gráfico 02

Modelo de Datos (DER)

Modelo relacional diseñado para optimizar las consultas analíticas, estructurando la información de candidatos, partidos, elecciones y resultados geográficos.

El diseño asegura la integridad referencial y facilita la creación de medidas complejas en Power BI para análisis comparativos inter-anuales.

2. Pipeline y Resultados

Flujo de datos desde el origen hasta el dashboard final de Power BI.

Gráfico 03

Flujo de Procesamiento

El pipeline automatiza la limpieza de nombres, estandarización de departamentos y consolidación de votos por mesa y municipio.

Se utilizan técnicas de validación de datos en cada etapa para asegurar que la información en la capa 'Gold' sea confiable para el reporte final.

Gráfico 04

Dashboard de Análisis Político

Visualización interactiva que permite filtrar resultados por partido, región y periodo electoral, identificando picos de votación y distribución geográfica.

El dashboard integra mapas de calor y gráficos de tendencia para ofrecer una visión clara del panorama político colombiano.

Recomendaciones

Recomendaciones Técnicas

A partir de la implementación de este pipeline, se sugieren las siguientes mejoras para la escalabilidad.

Implementar CI/CD

Integrar el despliegue de notebooks y esquemas SQL mediante Azure DevOps o GitHub Actions para automatizar las actualizaciones del pipeline.

Optimización de Delta Tables

Utilizar Z-Ordering en las columnas de ubicación y fecha para acelerar las consultas geoespaciales y temporales en grandes volúmenes de datos.

Monitoreo Proactivo

Configurar alertas de calidad de datos y fallos en el pipeline para asegurar la frescura y veracidad de la información política.

Enriquecimiento de Datos

Integrar fuentes externas como censos poblacionales o datos socioeconómicos para cruzar resultados electorales con indicadores de desarrollo.
