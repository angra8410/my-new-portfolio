Overview

Marco del proyecto

Este proyecto implementa una arquitectura moderna de datos (Medallion) para transformar registros crudos del mercado laboral en insights accionables, permitiendo el análisis de desempleo y participación laboral.

Objetivo

Crear una plataforma de datos escalable que centralice la información laboral dispersa y automatice su procesamiento.

Flujo de trabajo

  • Ingestión de datos a Fabric Lakehouse
  • Limpieza y transformación con PySpark
  • Modelado dimensional (Estrella) en SQL
  • Visualización analítica en Power BI

Qué muestra esta página

La arquitectura del sistema, el flujo de datos y los resultados visuales del dashboard de análisis laboral.

Análisis Visual

Arquitectura y Visualizaciones

El proyecto se estructura en tres capas principales: infraestructura, flujo de procesamiento y entrega de valor visual.

1. Infraestructura y Diseño

Diseño de la arquitectura del sistema y el modelo de datos para garantizar escalabilidad y rendimiento.

Gráfico 01

Vista General del Dashboard

Visualización de los KPIs principales del mercado laboral colombiano, incluyendo tasas de desempleo y participación global.

Esta vista permite a los tomadores de decisiones identificar rápidamente el estado actual de la fuerza laboral y las métricas clave de desempeño.

Gráfico 02

Tasa de Desempleo Anual

Análisis histórico de la tasa de desempleo desde 2019 hasta 2026, destacando los picos causados por factores económicos y globales.

El gráfico permite comparar el desempeño inter-anual y validar las tendencias de recuperación del mercado laboral.

2. Pipeline y Resultados

Flujo de datos desde el origen hasta el dashboard final de Power BI.

Gráfico 03

Análisis de Heatmap y Waterfall

Visualización de la distribución regional y los cambios incrementales en la fuerza laboral mediante gráficos de calor y cascada.

Se utilizan técnicas de validación de datos para asegurar que la información geográfica sea precisa para el análisis territorial.

Gráfico 04

Tendencias de Desempleo

Gráfico de líneas detallado que muestra la evolución temporal del desempleo y la relación entre empleados y desocupados.

El dashboard integra filtros interactivos para ofrecer una visión clara de las tendencias a largo plazo en el panorama laboral colombiano.

Recomendaciones

Recomendaciones Técnicas

A partir de la implementación de este pipeline, se sugieren las siguientes mejoras para la escalabilidad.

Implementar CI/CD

Integrar el despliegue de notebooks y esquemas SQL mediante Azure DevOps o GitHub Actions para automatizar las actualizaciones del pipeline.

Optimización de Delta Tables

Utilizar Z-Ordering en las columnas de ubicación y fecha para acelerar las consultas geoespaciales y temporales en grandes volúmenes de datos.

Monitoreo Proactivo

Configurar alertas de calidad de datos y fallos en el pipeline para asegurar la frescura y veracidad de la información.

Enriquecimiento de Datos

Integrar fuentes externas como censos poblacionales o datos socioeconómicos para cruzar resultados laborales con indicadores de desarrollo.
